# Acorde — Brand Kit

**Gestão em sintonia.**

Este pacote contém o sistema de identidade visual oficial **do projeto Acorde**: logotipos vetoriais, PNGs com transparência, ícones para aplicativos e navegadores, paleta, tipografia e tokens para Web/Flutter.

## Comece aqui

1. Leia `documentacao/GUIA_DA_MARCA.pdf` (guia visual) e `documentacao/GUIA_DA_MARCA.md` (regras completas).
2. Para seu README do GitHub, use `social/acorde-github-banner-1280x440.png`.
3. Para uma aplicação clara, use `logos/svg/acorde-horizontal-principal.svg`.
4. Para fundos escuros, use `logos/svg/acorde-horizontal-inverso.svg`.
5. Para app icon, use `icones/png/acorde-app-escuro-1024.png`.
6. Para estilos, integre `tokens/acorde.css` ou `tokens/acorde_colors.dart`.

### Organização

- `logos/svg/`: master vetorial, independente de fontes externas.
- `logos/png/`: exportações transparentes para uso rápido.
- `icones/`: favicon e ícones de aplicativo (incluindo Android adaptativo).
- `social/`: banner institucional para GitHub.
- `tokens/`: cores e tokens de identidade para React/Flutter.
- `documentacao/`: guia PDF e Markdown.
- `PREVIEW_ACORDE.png`: visão geral dos ativos do kit.

**Nota:** O wordmark dos SVGs é vetorizado. O kit não distribui arquivos de fontes. A reconstrução vetorial foi feita a partir da direção visual selecionada nas propostas; ainda é aconselhável uma checagem de propriedade intelectual e disponibilidade de marca antes de uso comercial.
