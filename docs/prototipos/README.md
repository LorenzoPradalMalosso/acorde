# Protótipos e fluxos de interface

A documentação inicial registra protótipos Web e Mobile criados no Google Stitch.

> Antes de publicar URLs neste repositório, confirmar acesso e permissões. Não adicionar links de convite privados, credenciais ou dados pessoais.

## Fluxos que precisam estar representados no MVP

1. Login de gestor e colaborador.
2. Gestor lista, cria e atribui tarefas pela Web.
3. Colaborador lista e conclui uma tarefa no Mobile.
4. Registro de tag verde elegível e dados para estimativa.
5. Gestor consulta dashboard operacional/ambiental.
