# Relatórios de sprint

Criar um relatório por semana ou sprint em arquivo Markdown (ex.: `semana-02.md`).

## Modelo

### Semana __ — Período __ a __

**Objetivo da sprint:**

**Planejado:**
- [ ] Issue # — Responsável — Requisito

**Entregue e integrado:**
- Issue / PR / evidência

**Testes realizados:**
- Caso / resultado / link de evidência

**Bloqueios e riscos:**
- Problema / impacto / plano de ação

**Feedback do professor ou usuários:**
- Observação / decisão tomada

**Participação da equipe:**
- Integrante / atividade / issue/PR

**Próximos passos:**
- [ ]

> Evitar inserir senhas, tokens, dados reais de participantes ou imagens sem autorização.
