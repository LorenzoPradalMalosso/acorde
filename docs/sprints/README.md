# Relatórios de sprint — Acorde 2.0

Criar um relatório por semana/sprint (ex.: `semana-02.md`). Registrar somente atividades realizadas e evidências existentes; não marcar como concluído trabalho planejado. Vincular entregas a requisitos `RF-v2-*` ou `RNF*` e registrar feedback/decisões.

## Modelo

### Semana __ — Período __ a __

**Versão do sistema:** Acorde 2.0<br>
**Objetivo da sprint:**

**Planejado:**
- [ ] Issue # — Responsável — RF-v2/RNF

**Entregue e integrado:**
- Issue / PR / evidência

**Testes realizados:**
- Caso / resultado / link da evidência

**Dados e metodologia:**
- Fator/fonte/versão usado, ou confirmar que os dados são fictícios de teste

**Bloqueios e riscos:**
- Problema / impacto / plano de ação

**Feedback do professor ou usuários:**
- Observação / decisão tomada

**Participação da equipe:**
- Integrante / atividade / issue/PR

**Próximos passos:**
- [ ]

> Não inserir senhas, tokens, dados pessoais sem autorização ou resultados de impacto sem metodologia e evidência.
