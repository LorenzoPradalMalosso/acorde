# Pacote do DER — Acorde

- `DER_Acorde.md` — documento principal com diagramas Mermaid e regras de integridade.
- `DER_MVP.png` / `.svg` — diagrama do MVP em imagem e vetor.
- `DER_Modulos.png` / `.svg` — mapa de entidades do sistema completo por áreas.
- `DER_MVP.mmd` — Mermaid do modelo principal editável.
- `DER_Modulos_Futuros.mmd` — Mermaid com módulos de expansão.
- `DER_Completo.dbml` — modelo lógico detalhado, editável no dbdiagram.io.

> O modelo é **proposto**, não representa estrutura já implementada. O MVP contém 7 entidades; os módulos adicionais ficam para evolução após priorização.
